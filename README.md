# ZONA ZERO Computación

Diseñá una landing page comercial moderna para una propuesta conceptual de ZONA ZERO Computación, un posible negocio de informática en Córdoba, Argentina.

OBJETIVO
Mostrar cómo podría verse una web profesional para un comercio de informática y facilitar que sus clientes soliciten información.

ESTILO

Diseño tecnológico, moderno y confiable.

Paleta azul oscuro, blanco y un color de acento.

Tipografía clara y excelente contraste.

Diseño responsive, priorizando celulares.

Animaciones sutiles, sin exagerar.

ESTRUCTURA

Encabezado con el nombre y navegación.

Hero con un título atractivo, texto breve y botón de contacto.

Sección de servicios de informática, utilizando textos provisionales claramente identificados hasta confirmar los servicios reales.

Sección que explique cómo solicitar una consulta.

Área de contacto con WhatsApp configurable y datos provisionales.

Pie de página.

REQUISITOS

Todo el contenido en español rioplatense natural.

No inventar teléfono, dirección, horarios, precios, reseñas ni servicios confirmados.

No inventar un enlace de WhatsApp.

Usar imágenes de recursos con licencia adecuada.

No agregar pagos, bases de datos, registro de usuarios ni funciones complejas.

Asegurar que los botones y la navegación funcionen.

Optimizar la página para pantallas pequeñas.

IMPORTANTE
Es una DEMO CONCEPTUAL INDEPENDIENTE, no una página oficial del negocio. Incluir discretamente una nota visible: "Propuesta visual no oficial, creada como ejemplo de diseño web". No afirmar que el negocio aprobó esta propuesta.

Primero construí una versión completa y visualmente atractiva. Priorizá una landing page sencilla, fácil de revisar y económica de mantener.
